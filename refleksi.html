Refleksi Anggota Kelompok

Deven Imanuel Iskandar

Apa yang saya pelajari

Dari project ini saya belajar bagaimana cara membuat sebuah website menggunakan HTML dan CSS. Saya juga belajar membuat beberapa halaman yang saling terhubung, memasukkan gambar, membuat tabel, dan mengatur tampilan website agar lebih menarik. Selain itu, saya belajar bekerja sama dengan anggota kelompok dalam menyelesaikan project.

Hal yang harus saya tingkatkan

Saya masih perlu meningkatkan kemampuan dalam memahami kode HTML dan CSS supaya bisa membuat website yang lebih rapi dan kreatif. Kedepannya saya ingin lebih banyak berlatih programming agar tidak hanya mengikuti contoh, tetapi juga bisa membuat dan mengembangkan website sendiri.

Karya Tuhan dalam Teknologi

Melalui project ini saya melihat bahwa Tuhan memberikan manusia kemampuan untuk belajar, berpikir, dan menciptakan sesuatu yang baru. Teknologi dan programming dapat menjadi salah satu cara untuk menggunakan pengetahuan tersebut dengan baik dan bermanfaat bagi orang lain.

Karena itu, kita harus menggunakan teknologi dengan bijak dan membuat sesuatu yang dapat memberikan manfaat bagi orang lain.
